## 🎯 Four-Agent System Explained

### Agent 1: Security Agent
**Purpose:** Detect threats and security issues
```
Detects:
  ✓ Brute force attacks (15+ failures/60s)
  ✓ Privilege escalation (ROOT by USER)
  ✓ Credential exposure (AWS keys)
  ✓ Data integrity violations
  ✓ Unauthorized access attempts
  
Output: CRITICAL/HIGH/MEDIUM/LOW findings
```

### Agent 2: Data Quality Agent
**Purpose:** Validate log format and structure
```
Checks:
  ✓ Timestamp completeness (ISO 8601)
  ✓ Trace ID presence (distributed tracing)
  ✓ Key-value structure validation
  ✓ Required field presence
  ✓ Format consistency
  
Output: Quality score (0-10) + recommendations
```

### Agent 3: Performance Agent
**Purpose:** Analyze system health and bottlenecks
```
Analyzes:
  ✓ Error rate (ERROR + CRITICAL count)
  ✓ Service timeouts
  ✓ Resource exhaustion
  ✓ Cascading failures
  ✓ System degradation patterns
  
Output: Health status + bottleneck identification
```

### Agent 4: Synthesis Agent (NEW!)
**Purpose:** Aggregate and summarize all findings with visualizations
```
Generates:
  ✓ Executive summaries
  ✓ Comprehensive metrics
  ✓ ASCII charts (terminal display)
  ✓ SVG charts (web/PDF)
  ✓ Professional HTML reports
  ✓ Prioritized recommendations
  
Output: Complete reports with charts, graphs, and statistics
```
