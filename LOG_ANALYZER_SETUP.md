# Log Analyzer - Login & Upload System

A secure web interface for uploading and analyzing log files on GitHub Pages with integrated authentication and multi-agent analysis.

## Features

✅ **Secure Login System**
- Demo credentials for testing
- Session management via localStorage
- User-friendly authentication interface

✅ **Log File Upload**
- Drag-and-drop file upload
- Support for .log and .txt files (up to 50MB)
- Real-time file validation

✅ **Intelligent Analysis**
- Automatic log parsing and categorization
- Security threat detection
- Pattern recognition
- Error/warning/info/debug counting
- IP extraction and tracking

✅ **Professional Dashboard**
- Real-time analysis results
- Multi-tab interface (Overview, Security, Patterns, Raw Data)
- Interactive statistics cards
- Responsive design

## File Upload Specifications

**Accepted Formats:**
- `.log` files
- `.txt` files

**Limitations:**
- Maximum file size: 50MB
- Processing is client-side (no server upload)
- Files are processed in browser memory

## Security Notes

⚠️ **Important:**
- Demo credentials are for testing only
- This is a client-side demo application
- No data is stored or transmitted to servers
- Session tokens stored in localStorage
- For production, implement proper backend authentication
- Consider implementing HTTPS and proper security headers

## Troubleshooting

### Issue: "Invalid username or password"
**Solution:** Use one of the demo credentials:
- `admin` / `security123`
- `analyst` / `analysis456`
- `reviewer` / `review789`

### Issue: Login redirects to login.html repeatedly
**Solution:** Clear localStorage and try again
```javascript
localStorage.clear();
```

### Issue: File upload not working
**Solution:** 
- Check file size (max 50MB)
- Verify file extension (.log or .txt)
- Check browser console for errors
- Ensure JavaScript is enabled

### Issue: Analysis results not showing
**Solution:**
- Ensure file content has recognizable patterns
- Check browser console for parsing errors
- Verify file is readable text format

## API Reference

### performAnalysis(content)
Analyzes log file content and returns analysis object.

**Parameters:**
- `content` (string): Log file content

**Returns:**
```javascript
{
    filename: string,
    fileSize: number,
    lineCount: number,
    timestamp: ISO8601,
    stats: {
        totalLines: number,
        errorLines: number,
        warningLines: number,
        infoLines: number,
        debugLines: number,
        uniqueIPs: number,
        failedLogins: number,
        successfulLogins: number
    },
    security: Array<SecurityFinding>,
    patterns: Object<string, number>
}
```
